# task

Pausing and scheduling for scripts.

This page is still being written. Check back soon for the full details.

## Members

| Member | What it does |
| --- | --- |
| wait | Pauses this script until the next step, then continues. |
| spawn | Starts a function right away on its own thread. |
| delay | Waits some seconds, then calls the function. |
| defer | Runs the function when the current step ends. |
