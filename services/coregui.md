# CoreGui

Built in interface elements like chat and the health bar.

This page is still being written. Check back soon for the full property and method lists.

## The player menu

Pressing Escape opens the menu with Settings, Help, and About tabs. The About tab carries the copyright line plus the full third-party licence terms in a scrolling view. The footer along the bottom names the exact build, like **Build 6**, with the source commit beside it, so a screenshot always says which build it was taken from.

## Properties

| Property | What it is |
| --- | --- |
| Name | The name you see in the Explorer. |
| Parent | Where it sits in the place tree. |
