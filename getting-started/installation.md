# Installation

Aero is a standalone creator-first multiplayer gaming platform. You make places in Studio, add behavior with Luau scripts, and test it all with Play. Right now Studio is the only download you need.

## What you need

A 64-bit Windows 10 or 11 PC. There is nothing else that you should need to install alongside that.

## Installing Aero Studio

1. Download the Aero Studio zip and extract it anywhere you like.
2. Open the folder and run Studio.exe.
3. The first time it opens, you will see a place that you can edit.

> A proper installer is planned that will let you pick which Aero apps to install and where to put them. Until then, the zip is how you install.

## What you can do

Feel free to look around the demo place. Click a part in the viewport, then check the Properties panel to see how it is put together. When you are ready, the Studio Tour walks through every panel.

Save with File, then Save. Places are saved as .aepl files. Keep them somewhere safe, since there is no cloud saving yet.

## If something goes wrong

Start with [Troubleshooting](troubleshooting.md). Script errors land in the Output panel, hard crashes show a dialog with a logs folder, and the common cases are listed there.
