# Kit

A named build that lives in the place. Copies sharing a `KitId` stay in sync while you edit.

## Properties

| Property | What it does |
| --- | --- |
| Name | The name you see in the Explorer. |
| Parent | Where it sits in the place tree. |
| KitId | The shared identity of linked copies. Empty means standalone. Editing it in Properties joins another kit's group, and clearing it unlinks this copy. |
